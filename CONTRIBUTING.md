## 开发环境配置

项目使用 Flutter 开发，主要是为了更方便地覆盖桌面端与移动端。  
需要先安装 Flutter 环境，具体可以参考 [Flutter 官方安装文档](https://docs.flutter.dev/install)。

```bash
flutter pub get
flutter run
```
移动端开发请自行安装Android Studio并配置安卓环境以及虚拟机
